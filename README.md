# 🦊 Ертегі Диктант

**Қазақша жазуды ертегі тыңдап үйренетін интерактивті веб-платформа.**

Мектеп оқушылары (1–6 сынып, 7–12 жас) қазақ ертегілерін YouTube-тан тыңдайды, видео әр сөйлемнен кейін өзі тоқтайды, бала естіген сөйлемді баспадан жазады, жүйе тексереді — дұрыс жазғанда ғана ертегі жалғасады. Осылайша бала «тыңдау → түсіну → жазу» тізбегі арқылы қазақ тілінде сауатты жазуды ойнай отырып меңгереді.

---

## 📌 Қысқаша

| | |
|---|---|
| **Мақсаты** | 7–12 жас оқушылардың қазақ тілінде диктант сауаттылығын дамыту |
| **Аудитория** | Оқушылар, мұғалімдер, әкімшілер |
| **Тілі** | UI толығымен қазақ тілінде (Ә ә, Ғ ғ, Қ қ, Ң ң, Ө ө, Ұ ұ, Ү ү, Һ һ, І і дұрыс қолданылады) |
| **Видео** | YouTube IFrame Player API (видео біздің серверімізде қайта қойылмайды, ресми embed арқылы) |
| **Мобильді** | Толық адаптивті: телефон, планшет, компьютер |

## 🧱 Мамандық құрылымы (architecture)

```
ertegi-diktant/
├── client/            # React 18 + Vite + TypeScript (алдыңғы жақ)
│   └── src/
│       ├── pages/     # Login, Library, Lesson, Progress, Dictionary, Settings, Teacher, Admin, 404
│       ├── components/# Header, Onboarding, Mascot (Жұсақ — SVG), KazakhKeyboard, Charts, Modal…
│       ├── lib/       # check.ts (сөз-сөзбен салыстыру + әріп-қате анықтау), sound.ts, tts.ts
│       └── styles/    # theme.css (ою-өрнек акценттері, dark/light, dyslexia режимі)
├── server/            # Node.js + Express + better-sqlite3 (артқы жақ)
│   └── src/
│       ├── index.js   # кіру нүктесі: API + статикалық фронтенд
│       ├── db.js      # SQLite схемасы
│       ├── seed.js    # демо деректер (6 ертегі, оқушылар, сынып, прогресс)
│       ├── check.js   # серверлік тексеру логикасы (қос қабатты қауіпсіздік)
│       └── routes/    # auth, tales, attempts, progress, teacher, admin
├── tools/             # ішкі құралдар (API тесті, скриншот, YouTube-уақыт құралдары)
├── render.yaml        # Render деплой конфигурациясы (blueprint)
└── docs/              # қазақша құжаттар (сипаттама, соттаушылар нұсқаулығы, демо сценарийі)
```

**Дерекқор (SQLite, 9 кесте):** `users` (роль, аватар, баптаулар, XP, серия), `tales` + `segments` (ертегілер мен белгіленген сөйлемдер), `attempts` + `attempt_answers` (әр бөлік бойынша детальды нәтиже, әріп қателері), `dictionary_words` (бала сөздігі), `classes` + `class_members` + `homework` (мұғалім панельдері), `user_badges` (марапаттар).

**Қалыпты оқу ағыны (Lesson):**
1. YouTube IFrame Player API арқылы видео жүктеледі (`enablejsapi=1`).
2. Скрипт `requestAnimationFrame`/`~200ms` интервалымен уақытты сұрайды: сегмент соңына жеткенде — **авто-пауза**.
3. Жазу аймағы белсендіріледі, курсор орналастырылады, қазақ әріптері тақтасы (ә ғ қ ң ө ұ ү һ і) қолжетімді.
4. «Тексеру» → сөз-сөзбен салыстыру: дұрыс сөздер жасыл, қате сөздер қызғылт, жетіспейтін сөздер үзік сызықпен. 2 қатеден кейін дұрыс нұсқа көрсетіледі.
5. Қазақ ерекше әріптерінің шатасуы жеке анықталады: «Мұнда «қ» әрпі керек сияқты» (қ/к, ғ/г, ә/а, ө/о, ұ/у, ү/у, ң/н, і/и, һ/х).
6. 3 кезеңді көмек: 1) сөз саны, 2) әр сөздің бастапқы әрпі, 3) сөйлемді 3 сек. көрсету (әрбірі аз XP-ға тұрады).
7. Дұрыс жауап → сөйлем «Менің жазған ертегім» тақтасына қосылады → видео келесі сегменттен жалғасады.
8. Соңында: жұлдыздар (1–3), XP, дәлдік, қиын сөздер, бүкіл ертегіні PDF ретінде шығару/сақтау.

## 🚀 Жергілікті іске қосу (local setup)

Талаптар: Node.js 20+.

```bash
npm run setup        # server + client пакеттерін орнатады
npm run build        # фронтендті құрастырады (client/dist)
npm start            # сервер: http://localhost:4000
```

Демо деректер бос дерекқорда **өзі жүктеледі** (6 ертегі, 3 рөлдің есептері, сынып, прогресс). Қайта себу: `npm run seed -- --force`.

Ойыншық режим: `npm run dev:server` + `npm run dev:client` (Vite 5173, API прокси 4000-ге).

## 📚 Жаңа ертегі қосу (мұғалім/әкімші, кодсыз)

1. **«Әкімші» бөлімі → «Жаңа ертегі»:** YouTube сілтемесін жазыңыз → «Табу» → видео ID, атауы, бекет (thumbnail) автоматты жүктеледі. Деңгей (1–3), санат, жас, ұзақтығын белгілеңіз.
2. **«✏️ Сегмент» редакторы:** ертегі мәтінін қойыңыз → сөйлемдерге автоматты бөледі → **видео ойнап тұрғанда** «⏺ Басын белгіле» / «⏹ Соңын белгіле» батырмаларымен әр сөйлемнің уақытын қою; уақытты қолмен де жазуға болады. Сөйлемдерді біріктіру, бөлу, ретін ауыстыру, «preview» (бөлікті тыңдау) бар.
3. Сақтаңыз — ертегі кітапханада бірден пайда болады.

Видео қолжетімсіз болса (YouTube лицензия шектеуі) — балаларға жылы қазақша хабарлама шығады, басқа ертегі ұсынылады.

## 🤖 Қайда және қалай AI қолданылды

Бұл жобаның ядролық тексеру логикасы **детерминистті алгоритм** (AI-сыз) — балаларға берілетін кері байланыс әрқашан дәл және талқыланып жазылған:

- **Сөйлемдерді бөлу (admin):** «Мәтінді бөлу» батырмасы сөйлем шекарасын (`. ! ? …`) тауып, сегменттерге бөледі — қарапайым лингвистикалық ереже, AI-сыз. Мұғалім әр нәтижені растайды немесе түзетеді (human-in-the-loop).
- **Көмек хабарламалары:** әріп-қате анықталғанда («Мұнда «қ» әрпі керек сияқты») — ережелік жүйе: 9 жұп қазақ ерекше әрпі бойынша анықтама + жылы тондағы қалыптастырылған хабар.
- **AI қолданылмаған жерлер:** жауап тексеру, XP/жұлдыз есептеу, баға қою. Бұл балалар үшін әділдік пен болжамдылықты қамтамасыз етеді.

> **Технологиялар (бәсеке сұрауына):** React 18, TypeScript, Vite, Express.js, SQLite (better-sqlite3), JWT, YouTube IFrame Player API, Web Speech API (сөз оқыту), Canvas/SVG (маскот, ою-өрнек, графиктер), PDF шығару (window.print). AI: сөйлемдерді бөлу көмекшісі (ережелік, адам растайды).

## ☁️ Деплой ( Render-ға, 2 минут)

Код: https://github.com/ayazhannb/ertegi-diktant — `render.yaml` (blueprint) дайын.

1. **https://render.com** — «Log in» → GitHub-пен кіру (тегін есеп).
2. **«New» → «Blueprint»** (немесе «New Web Service» → «Connect Repository») → репозиторий **ayazhannb/ertegi-diktant**, branch `main` таңдаңыз. Render `render.yaml`-ді өзі оқиды: build/start командтары, 1 GB disk, `JWT_SECRET` (auto-generate) орнайды.
3. **«Apply Blueprint»** (немесе «Create Service») → 2–4 минутта дайын болады. Сервер бірінші іске қосылғанда демо деректер өзі жүктеледі.

Нәтиже: `https://ertegi-diktant.onrender.com` (немесе сіз таңдаған атымен `.onrender.com`) — HTTPS, кез келген компьютер/телефоннан ашылады.

**Маңызды:** Render тегін жоспарда сервис 15 минут бос тұрса ұйықтайды; келесі сұраныс 30–60 сек ішінде оятады (бұл «wake-up» ретінде көрінеді — қалыпты жағдай).
