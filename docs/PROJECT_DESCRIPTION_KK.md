# Жоба сипаттамасы (бәсеке сұрауына, 150–200 сөз)

**Жоба атауы:** Ертегі Диктант

**Мәселе.** Қазақ мектеп оқушылары ана тілінде еркін жазу дағдысын жеткілікті жаттықтай алмайды: дәстүрлі диктант қызықты емес, ал балалар ұнататын мазмұн — ертегілер. Интернетте қазақша ертегі видеосы көп, бірақ оларды тыңдап, естігенін жазуды жүйелі жаттықтыратын құрал жоқ.

**Шешім.** «Ертегі Диктант» — интерактивті веб-платформа: бала қазақ ертегісін тыңдайды, видео әр сөйлемнен кейін автоматты түрде тоқтайды, бала естіген сөйлемді баспадан жазады, жүйе сөз-сөзбен тексеріп, жылы кері байланыс береді — дұрыс жазғанда ғана ертегі жалғасады. Қазақ ерекше әріптерінің (қ, ғ, ә, ө, ұ, ү, ң, і, һ) шатасуын жүйе анықтайды: «Мұнда «қ» әрпі керек сияқты». Көмек деңгейлері, жұлдыздар, XP, марапаттар, сөздік ойын мен «Менің жазған ертегім» PDF-сі баланың қызығушылығын сақтайды. Мұғалім панельдерінде сынып прогресі, ең қиын сөздер мен әріп қателерінің аналитикасы, үй тапсырма тағайындау бар; әкімші код жазбай жаңа ертегілер мен сегменттерді қосады.

**Мақсатты аудитория.** 1–6 сынып оқушылары (7–12 жас), мұғалімдер, ата-аналар.

**Технологиялар.** React + TypeScript, Node.js/Express, SQLite, JWT, YouTube IFrame Player API, Web Speech API. UI толығымен қазақ тілінде.

**Қазақ тілін дамытуға қосылатын үлесі.** Платформа «тыңдау → түсіну → жазу» циклін ойын түрінде қалыптастырады: бала ертегі мәтінін есту, оқу және дұрыс жазу арқылы емле сауаттылығын, сөздік қорын мен ана тілінде ой жеткізу дағдысын жүйелі меңгереді.
